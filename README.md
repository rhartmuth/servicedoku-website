# ServiceDoku Website – ENTWURF

**Nicht öffentlich freigegeben.** Die Seiten `impressum.html`, `datenschutz.html` und `support.html` enthalten noch sichtbare Platzhalter. Vor der Veröffentlichung vollständig ausfüllen und rechtlich prüfen.

## GitHub Pages

Nach Freigabe unter **Settings → Pages → Deploy from a branch → main → /(root)** veröffentlichen.

Die Website verwendet keine externe Schrift, kein Tracking und keine extern geladenen JS-Bibliotheken. `noindex, nofollow` ist bis zur Freigabe in allen Seiten gesetzt, verhindert aber nicht den öffentlichen Zugriff, falls GitHub Pages aktiviert wird.

Die Startdatei `index.html` muss im Repository-Hauptverzeichnis liegen; `assets/` daneben.
